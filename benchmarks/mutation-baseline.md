# Mutation baseline

Generated by `scripts/mutation-baseline.sh --write`. Do not hand-edit.

Each selftest is a battery of fixtures where one property is FALSE and the
subject must go red. The count is what that suite actually EXECUTED, not what
its source appears to contain -- a case present and unreachable is precisely
what a static count would miss.

**This is a trend, not a target.** The gate fires in one direction only: a
count that FALLS. There is no correct number of cases, and a floor invented
here would be a threshold nobody derived.
